Get Started

Quickly integrate Mozek into your Angular application.

Welcome to Mozek! This guide will help you set up your environment and start building with our high-performance, signal-based UI component library. Mozek offers a rich set of components designed to be lightweight, flexible, and easy to use right out of the box. By the end of this guide, you'll be ready to create stunning interfaces with ease.

We assume you already have the Angular CLI installed.



Install Mozek

To begin, install the Mozek package via npm:

npm install mozek-angular

@if (textCopied('copyNpm')) { check_circle} @else { copy}

You're all set! Mozek is now ready for use in your application.



Import a Component

Since Mozek components are standalone, you can import them directly into your components. Don't forget to add them to your imports array:

import { MozButton } from 'mozek-angular';

@Component({
  ...
  imports: [ MozButton ]
})

@if (textCopied('copyImport')) { check_circle} @else { copy}

Now you're ready to use the component in your template:

<moz-button>Click Me</moz-button>

@if (textCopied('copyTag')) { check_circle} @else { copy}


Run Your Application

Launch your development server to see Mozek in action:

ng serve

@if (textCopied('copyServe')) { check_circle} @else { copy}

Visit http://localhost:4200 in your browser to see your new UI. Happy building!
