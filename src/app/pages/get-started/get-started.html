Getting Started

Quickly integrate Mozek into your Angular application.

Mozek is a modern, high-performance UI component library built entirely on Angular Signals. This guide will walk you through setting up Mozek in a new or existing Angular project.

Professor's Note: Before proceeding, ensure you have Node.js installed and the Angular CLI available in your environment.
1. Install the Package

Install the mozek-angular package via npm. This provides all the core components and styles you need.

npm install mozek-angular

@if (textCopied('copyNpm')) { check_circle} @else { copy}
2. Setup Styles

Ensure that your application can load the required styles. If you are using SCSS, you can import Mozek styles in your global styles.scss file:

@use "mozek-angular/src/styles" as moz;

@if (textCopied('copyStyles')) { check_circle} @else { copy}
3. Import a Component

Mozek components are provided as Standalone Components. Import them directly into the components where they are needed.

import { MozButton } from 'mozek-angular';

@if (textCopied('copyImport')) { check_circle} @else { copy}

Then, use the component in your template:

<moz-button model="fill" color="primary">Click Me</moz-button>

@if (textCopied('copyTag')) { check_circle} @else { copy}
4. Serve Your App

Start your development server to see your new component in action.

ng serve

@if (textCopied('copyServe')) { check_circle} @else { copy}

Navigate to http://localhost:4200 in your browser to view the application.
