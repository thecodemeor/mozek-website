Color Palettes

Mozek theme help maintain consistent use of color throughout your app. Mozek provides palettes for theme colors and primitives that you can use as a foundation for your design system.

In SCSS, colors are accessed using the:

#{moz.moz-get-color([color], [n])}

@if (copiedId() === 'target') { check_circle } @else { copy }

where [color] is the name of the palette and [n] is the numeric value of the desired swatch.

Example usage in SCSS:

.my-class {
  color: #{moz.moz-get-color(blue, 600)};
  background-color: #{moz.moz-get-color(blue, 50)};
}

You can change the primary color, button styles, and other design tokens by using the code below.
