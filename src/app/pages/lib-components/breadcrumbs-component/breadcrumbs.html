Basic Breadcrumbs

A standard breadcrumb trail with icons and labels. Each item can optionally include a URL for navigation.

The navigation components in Mozek accept an array of objects. Each object must follow a specific schema containing three properties: label, icon, and url.

Property:

{label:, icon:, url:}

Source Code arrow_alt_down

basicItems = [
@for (item of basicItems; track item) { { label: '{{item.label}}', icon: '{{item.icon}}', url: '{{item.url}}' },
} ];

Auto-Collapsing

When the breadcrumb trail exceeds the container width, it automatically collapses intermediate steps into a menu, keeping only the first and last items visible.

Simulated Narrow Container (Drag handle to resize)

collapsedItems = [
@for (item of collapsedItems; track item) { { label: '{{item.label}}', icon: '{{item.icon}}'},
} ];
