To implement an onboarding step, use the moz-tutor component to define your content and mozTutorFor directive on the element you wish to highlight.

Guided Step

Define a tutorial step and trigger it programmatically or via user interaction. The target element will be highlighted while the rest of the screen is dimmed.

Directive:

mozTutorFor

Value: MozTutor
